**Results:** My p-value was approximately 0.05759. Since this is greater than 0.05, I failed to reject the null hypothesis. There is not enough evidence to conclude that right-handedness is significantly more common than left-handedness among these toads.

**Results:** My two-tailed p-value was approximately 0.33477. Since this is greater than 0.05, I failed to reject the null hypothesis. There is not enough evidence to conclude that right-handedness differs significantly between male and female toads.

## 5.2 Assortative Mating in Animals

### Part 1

For this question, I created a function that takes a taxon as input and calculates the mean correlation coefficient (r) for that group. I used the Jiang2013 dataset and selected the r values that matched the taxon entered into the function.

**R Code:**

```r
jiang <- read.csv("Jiang2013_data.csv", sep="\t")
head(jiang)

mean_r <- function(taxon){
  values <- jiang$r[jiang$Taxon == taxon]
  mean(values)
}

mean_r("Fish")
```

**Result:** The mean r value for fish was 0.3971901.


### Part 2

For this question, I wanted to determine whether the mean r value for fish was unusually high compared to the entire dataset. I used 50,000 randomizations, randomly selecting 37 r values each time because there were 37 observations for fish. I calculated the mean for each sample and compared it to the observed mean for fish.

**R Code:**

```r
means <- c()
nExp <- 50000

for(i in 1:nExp){
  experiment <- sample(jiang$r, size=37, replace=F)
  means[i] <- mean(experiment)
}

sum(means >= mean_r("Fish"))/nExp
```

**Result:** My p-value was approximately 0.00322. Since this is less than 0.05, I rejected the null hypothesis. This suggests that fish have a significantly higher mean r value than expected from randomly sampling the entire dataset.

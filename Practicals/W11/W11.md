## 5.1 pch Symbols

For this question, I recreated the figure showing the 26 plotting symbols in R without using `expand.grid()`.

### R Code

```r
# Week 11 Practical
# 5.1 pch Symbols

# Create an empty plot
plot(0, 0, type="n",
     xlim=c(0, 11), ylim=c(0, 7),
     xlab="", ylab="", axes=F)

# Add the first row of symbols (0-4)
points(c(2, 4, 6, 8, 10), rep(6, 5),
       pch=0:4, cex=1.5)
text(c(1, 3, 5, 7, 9),
     rep(6, 5), labels=0:4)

# Add the second row of symbols (5-9)
points(c(2, 4, 6, 8, 10), rep(5, 5),
       pch=5:9, cex=1.5)
text(c(1, 3, 5, 7, 9),
     rep(5, 5), labels=5:9)

# Add the third row of symbols (10-14)
points(c(2, 4, 6, 8, 10), rep(4, 5),
       pch=10:14, cex=1.5)
text(c(1, 3, 5, 7, 9),
     rep(4, 5), labels=10:14)

# Add the fourth row of symbols (15-19)
points(c(2, 4, 6, 8, 10), rep(3, 5),
       pch=15:19, cex=1.5)
text(c(1, 3, 5, 7, 9),
     rep(3, 5), labels=15:19)

# Add the fifth row of symbols (20-24)
points(c(2, 4, 6, 8, 10), rep(2, 5),
       pch=20:24, cex=1.5)
text(c(1, 3, 5, 7, 9),
     rep(2, 5), labels=20:24)

# Add the final symbol (25)
points(2, 1, pch=25, cex=1.5)
text(1, 1, labels=25)

box()
```

### Explanation

I started by using `plot()` to create an empty graph and then used `points()` to add the different plotting symbols. I arranged them in rows of five and used `text()` to label each symbol with its number. I also used `pch` to choose the symbols and `cex` to adjust their size.

One thing I wasn't sure about was how to create an empty plot, remove the numbered axes, and add a border to make my figure look like the example. I looked online for clarification and found that `type="n"` creates an empty plot, `axes=F` removes the axes, and `box()` adds a border. After adding these, my figure looked much closer to the original.
